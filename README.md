## Silkweb

Silkweb is an **LLM-native Python web scraping library** (scaffold).

- **Status**: scaffolding only (public API + config + exceptions)
- **Python**: 3.10+

### Install

```bash
pip install -e .
```

### Development

```bash
python -m pip install -e ".[all]"
ruff check .
ruff format .
```
